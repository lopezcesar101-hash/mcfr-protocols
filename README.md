# MCFR Protocols — Fast Lookup + Ask AI

A webapp built on the **Monroe County Fire Rescue EMS Protocols, 2025 Version V4**
(the county's current protocol book, effective January 5, 2026) —
styled after the book itself: same table-of-contents order, same page look.

- **Protocols tab:** the book's table of contents (82 protocols + the medication
  formulary's two sections), searchable, each opening as a book-style page with its
  book page number. Chart pages (cardiac arrest algorithms, START/JumpSTART triage,
  trauma alert criteria, the burn TBSA chart, TXA/whole blood) show the official
  book page as an image.
- **Ask AI tab:** ask a question in plain words. The AI (Google Gemini, free key the
  user pastes once — stored only on their device) answers strictly from the book's
  own sections and cites the book pages it used.
- All protocol content is taken directly from the official 2025 V4 book — nothing
  added or paraphrased in the lookup. Lookup aid only; always confirm against the
  official protocol book and current medical direction before acting.
